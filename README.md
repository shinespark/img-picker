# img-picker

右クリックした画像を PNG に変換してクリップボードへコピーする Chrome 拡張（Manifest V3）。コピーした画像は直近数件がキャッシュされ、ツールバーのポップアップからいつでも貼り直せます。

`<img>` だけでなく、CSS の背景画像・`<canvas>`・インライン SVG・`<video>` のポスター画像も拾えるのが特徴です。

## 特徴

- **どこの画像でもコピーできる** — `<img>` / CSS `background-image` / `<canvas>` / インライン SVG / `<video>` の poster に対応
- **常に PNG** — WebP や AVIF など、貼り付け先が対応していない形式も PNG に変換してからコピーします
- **CORS で諦めない** — 画像の取得は service worker 側で行うので、直接 fetch すると弾かれるサイトの画像も取れます
- **直近のコピーを再利用できる** — 履歴をポップアップにサムネイル表示。クリックで再コピー、個別削除・全削除も可能
- **iframe の中でも動く** — 全フレームに注入されるため、埋め込みページ内の画像も対象です
- **日本語 / 英語対応** — ブラウザの表示言語に従って切り替わります

## インストール

Chrome ウェブストアには公開していないため、ソースから読み込みます。

```sh
git clone https://github.com/shinespark/img-picker.git
```

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** をクリックし、クローンしたリポジトリの**ルートディレクトリ**を選ぶ

## 使い方

### コピーする

ページ上の画像を右クリックし、**「画像をクリップボードにコピー」** を選ぶだけです。成功すると画面右下に「コピーしました」と表示されます。

メニューは画像以外を右クリックしたときにも表示されます（CSS 背景画像などは Chrome が「画像」と認識しないため）。画像が見つからなかった場合はその旨が表示されます。

### 履歴から貼り直す

ツールバーの拡張機能アイコンをクリックするとポップアップが開き、コピー済みの画像がサムネイルで並びます。

| 操作 | 結果 |
| --- | --- |
| サムネイルをクリック | その画像をクリップボードへ再コピーし、先頭に繰り上げる |
| サムネイル右上の × | その 1 件を削除 |
| ヘッダーの「保持 N 件」 | 履歴の保持件数を変更（10 / 20 / 30 / 50、既定は 20） |
| フッターの「すべて削除」 | 履歴を空にする |

## 仕様と制限

- コピーされるのは常に **PNG** です。アニメーション GIF は 1 コマ目の静止画になります。
- 履歴は `chrome.storage.local` に保存されます。**大きすぎる画像（data URL 換算で 2MB 超、元データで約 1.5MB 超）はクリップボードへのコピーは行いますが、履歴には残りません**（ストレージを圧迫するため）。
- 履歴は端末内にのみ保存され、外部へ送信されることはありません。
- `<canvas>` の内容は、他オリジンの画像が描かれている場合（tainted canvas）ブラウザ側の制約で読み取れないことがあります。

## 権限について

| 権限 | 用途 |
| --- | --- |
| `contextMenus` | 右クリックメニューの項目を追加する |
| `storage` | コピーした画像の履歴と保持件数を保存する |
| `clipboardWrite` | クリップボードへ書き込む |
| `host_permissions: <all_urls>` | 任意のサイトの画像を取得する（CORS 回避のため service worker から fetch する） |

## 開発

ビルドツール・パッケージマネージャ・テストフレームワークは使っていません。素の JS / HTML / CSS をそのまま Chrome が読みます。

```
manifest.json          拡張のルート。パスはすべてここ起点
icons/
  icon.svg             アイコンの原本
  icon*.png            SVG から書き出したもの（Chrome は SVG を受け付けないため）
_locales/
  en/messages.json     既定ロケール
  ja/messages.json
src/
  background.js        service worker（メニュー登録・画像の fetch・履歴の書き込み）
  content.js           全ページ・全フレームに注入（対象の特定・PNG 化・クリップボード書き込み）
  popup/               popup.html / popup.js / popup.css（履歴の表示と再コピー）
```

変更を反映させるとき、`src/content.js` と `src/popup/*` はページの再読み込みで済みますが、`src/background.js` と `manifest.json` を触った場合は `chrome://extensions` で拡張自体の再読み込み（更新ボタン）が必要です。

ログの出力先はコンテキストごとに分かれます。

- service worker: 拡張の詳細ページの「Service Worker」リンク
- content script: 対象ページの DevTools
- popup: ポップアップを右クリック →「検証」

設計上の判断や実装の意図は [CLAUDE.md](CLAUDE.md) にまとめています。

### 文言の追加

ユーザー向けの文字列はコードに直接書かず、`_locales/en/messages.json` と `_locales/ja/messages.json` の**両方に同じキー**を追加して `chrome.i18n.getMessage()` で取り出します。
